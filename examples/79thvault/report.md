- Seller B's 238 Tornado deposits (2,283.7 BNB) are summarised, not included as edges.
- 15 one-hop relays from the collection wallet (20-50 BNB each) show nonce 0 and balance 0 at latest; how the funds left them is not explained by plain transactions.
- Contract-internal native transfers are not traced (no trace API used).
- Labels come from a bundled list; an unlabelled address is not proof that it is a private wallet.
